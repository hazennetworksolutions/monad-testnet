## 📋 Overview

Monad is a high-performance EVM-compatible Layer 1 blockchain. This repository contains step-by-step guides for setting up a Monad testnet full node and registering as a validator through the Monad Validator Delegation Program (VDP).

The **Validator Delegation Program (VDP)** selects node operators based on uptime, performance, and community contribution. Selected validators receive a Foundation delegation of **10,000,000+ MON** to participate in consensus.

- Official Docs: [docs.monad.xyz](https://docs.monad.xyz/node-ops/full-node-installation)
